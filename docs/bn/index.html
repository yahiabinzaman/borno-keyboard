বর্ণ (Borno)
বৈশিষ্ট্যসমূহ লাইভ টাইপিং ইনস্টলেশন GitHub English  ডাউনলোড
 অ্যাপল সিলিকন নেটিভ • M1, M2, M3, M4 এবং M5 এর জন্য নির্মিত

ম্যাকে বাংলা লেখার চিরচেনা আনন্দ।
উইন্ডোজের মতোই ফাস্ট, কোনো প্রিভিউ ছাড়াই।

ম্যাকের জন্য নিয়ে এলো সম্পূর্ণ নতুন বর্ণ (Borno)। কোনো বিরক্তিকর ভাসমান প্রিভিউ বক্স ছাড়াই সরাসরি টাইপিং — যা অ্যাডোবি ইলাস্ট্রেটর, ফটোশপ ও প্রতিদিনের কাজের জন্য বিশেষভাবে প্রস্তুত।

ম্যাকের জন্য ডাউনলোড করুন
brew install --cask borno
বর্ণ ডিরেক্ট ফোনেটিক ইঞ্জিন — সরাসরি টাইপ করে পরখ করুন
⚡️ নিচে ইংরেজিতে লিখুন (অভ্র ফোনেটিক অনুযায়ী):
সরাসরি বাংলা আউটপুট:
আমি বাংলায় গান গাই
ক্লিক করে পরখ করুন:

কেন ক্রিয়েটর ও ডিজাইনাররা বর্ণ পছন্দ করেন

ম্যাকের শক্তিশালী পারফরম্যান্সের সাথে নিখুঁত টাইপিংয়ের মেলবন্ধন।

কোনো প্রিভিউ ছাড়া সরাসরি টাইপিং (উইন্ডোজের মতো ফিল)

মাউস বা কার্সরের পিছু পিছু কোনো বিরক্তিকর সাজেশনের বক্স ঘুরবে না। আপনি যখন ফোনেটিক টাইপ করবেন, বর্ণ সরাসরি অক্ষরের জায়গায় নিখুঁত বাংলা বসিয়ে দেবে—ঠিক যেমন উইন্ডোজ অভ্রতে আপনি অভ্যস্ত ছিলেন।

নেটিভ অ্যাপল সিলিকন (Apple Silicon)

রোসেটা ইমুলেশনের প্রয়োজন নেই। M1, M2, M3, M4 ও M5 চিপের আর্কিটেকচারে সম্পূর্ণ সুইফট ও রাস্টে তৈরি। শূন্য ব্যাটারি অপচয় ও সেকেন্ডে রেসপন্স।

অ্যাডোবি ইলাস্ট্রেটর ও ডিজাইনার ফ্রেন্ডলি

ইলাস্ট্রেটরে Bornomala, Kalpurush বা যেকোনো ইউনিকোড ফন্টে কার্সর হারিয়ে যাওয়া বা প্রিভিউ আটকে থাকার কোনো ঝামেলা নেই। স্মুথ ভেক্টর টেক্সট টাইপিং।

১০০% অফলাইন ও সম্পূর্ণ নিরাপদ

বর্ণ কিবোর্ড আপনার কম্পিউটারের বাইরে ইন্টারনেটে কোনো ডেটা পাঠায় না। কোনো কি-লগিং বা ট্র্যাকিং নেই। আপনার ব্যক্তিগত লেখা ও ফাইল সম্পূর্ণ নিরাপদ।

ইনস্টল করার ৩টি সহজ ধাপ

মাত্র ১ মিনিটের মধ্যে আপনার ম্যাকে প্রস্তুত হয়ে যাবে।

১

ডাউনলোড ও ইনস্টল

অফিশিয়াল বর্ণ ডিএমজি (DMG) ফাইল ডাউনলোড করুন অথবা টার্মিনালে Homebrew দিয়ে ইনস্টল করুন।

২

ইনপুট সোর্সে যোগ করুন

System Settings → Keyboard → Input Sources-এ যান, + বাটনে ক্লিক করে Borno সিলেক্ট করুন।

৩

সুইচ ও টাইপিং

⌃ Control + ␣ Space অথবা কিবোর্ডের 🌐 Globe বাটন চেপে যখন খুশি বাংলা চালু করুন!
