বর্ণ (Borno)
বৈশিষ্ট্য লাইভ টেস্ট ইনস্টলেশন GitHub English ডাউনলোড
macOS 13+ • অ্যাপল সিলিকন নেটিভ (M1–M5)

ম্যাকের জন্য আধুনিক অভ্র ফোনেটিক কিবোর্ড।

কোনো ভাসমান প্রিভিউ বক্স ছাড়াই সরাসরি টাইপিং। অ্যাডোবি ইলাস্ট্রেটর ও ডিজাইনারদের কাজের জন্য নিখুঁত এবং ১০০% নির্ভরযোগ্য।

ম্যাকের জন্য ডাউনলোড (.dmg)
$ brew install --cask borno
বর্ণ সরাসরি টাইপিং টেস্ট — TextEdit.app
ইংরেজিতে টাইপ করুন (অভ্র ফোনেটিক অনুযায়ী):
আমি বাংলায় গান গাই
ক্লিক করে দেখুন:

কাজের সুবিধার জন্য বিশেষভাবে প্রস্তুত

প্রতিটি কি-স্ট্রোক সরাসরি কনভার্ট হয় কোনো অপ্রয়োজনীয় পপআপ ছাড়া।

DIRECT INPUT

জিরো-প্রিভিউ সরাসরি টাইপিং

মাউস কার্সরের পিছু পিছু কোনো প্রিভিউ উইন্ডো বা সাজেশনের বক্স আসবে না। আপনি যেভাবে উইন্ডোজ অভ্রতে টাইপ করতেন, বর্ণ ঠিক সেভাবেই ক্যানভাসে সরাসরি বাংলা রূপান্তর করে।

ARCHITECTURE

নেটিভ অ্যাপল সিলিকন

M1, M2, M3, M4 এবং M5 এর জন্য পিওর ARM64 বাইনারি। রোসেটার কোনো প্রয়োজন নেই, মুহূর্তের মধ্যে চালু হয় এবং ব্যাটারি সাশ্রয়ী।

DESIGNER WORKFLOW

অ্যাডোবি ইলাস্ট্রেটর ও ফটোশপ

ইলাস্ট্রেটরে Bornomala, Kalpurush বা অন্য ইউনিকোড ফন্টে কার্সর হারিয়ে যাওয়া বা ক্যানভাস লক হয়ে যাওয়ার ঝামেলামুক্ত মসৃণ টাইপিং।

SECURITY & PRIVACY

১০০% অফলাইন ও সম্পূর্ণ নিরাপদ

বর্ণ কিবোর্ড ইন্টারনেটে কোনো ডেটা পাঠায় না। কোনো কি-লগিং বা ট্র্যাকিং নেই। ওপেন সোর্স (MPL-2.0) লাইসেন্সের অধীনে তৈরি।

ইনস্টল করার সহজ নিয়ম

মাত্র এক মিনিটের মধ্যে প্রস্তুত হয়ে যাবে।

ধাপ ০১

ডাউনলোড করুন

.dmg ফাইলটি ডাউনলোড করে ইনস্টল করুন অথবা Homebrew দিয়ে ইনস্টল করুন।

ধাপ ০২

ইনপুট সোর্সে যোগ করুন

System Settings → Keyboard → Input Sources-এ গিয়ে + চেপে Borno যোগ করুন।

ধাপ ০৩

সুইচ ও টাইপ

⌃ Control + ␣ Space অথবা 🌐 Globe চেপে যেকোনো সময় চালু করুন।
