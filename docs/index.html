Engineered for Focus

Every keystroke converted seamlessly with zero distractions.

Direct Input Engine

Zero-Preview Direct Typing

Unlike standard macOS IMEs that open a floating candidate window following your cursor, Borno converts letters inline directly into your canvas. Exactly what Windows Avro users expect.

Architecture

Apple Silicon Native

Built purely for ARM64 (M1, M2, M3, M4, M5). No Rosetta emulation, zero battery overhead, and instant launch.

Creative Suite

Adobe Illustrator & Photoshop

Engineered to prevent cursor glitches, focus lost, and character dropped in Illustrator with Bornomala, Kalpurush, and all Unicode Bengali fonts.

Security & Privacy

100% Offline & Private

Borno makes zero network requests. No background telemetry, no analytics, no keylogging. Fully open source under the MPL-2.0 license.

Quick Installation

Ready to write in less than a minute.

STEP 01

Install Borno

Download the .dmg installer and run it, or install via Homebrew.

STEP 02

Enable Input Source

Go to System Settings → Keyboard → Input Sources, click + and add Borno.

STEP 03

Switch & Type

Toggle language anytime using ⌃ Control + ␣ Space or 🌐 Globe.
