STEP-BY-STEP SETUP

Get Started in 3 Simple Steps

🍎 macOS SETUP

macOS (Ventura, Sonoma, Sequoia)

1. Run the 1-line terminal command or download Borno.dmg.

2. Open System Settings → Keyboard → Input Sources (Edit...). Click +, search for Borno, and add it.

3. Press Control + Space or tap the Globe (🌐) key anytime to switch input methods.

Download Borno.dmg
🪟 WINDOWS SETUP

Windows 10 / 11

1. Run the 1-line PowerShell script or download Borno-Setup-0.2.5.exe.

2. Borno runs quietly in your System Tray near the taskbar clock.

3. Press F12 anytime to toggle between English and Bengali mode across all Windows apps.

COMMON QUESTIONS

Frequently Asked Questions

How do I type in Adobe Illustrator without broken vowel boxes? ▼
Simply switch Borno's Output Encoding to ANSI from the macOS Menu Bar or Settings. In Illustrator or Photoshop, select your ANSI font (e.g. SutonnyMJ) and type normally. Borno automatically reorders all vowels and conjuncts!
Does Borno collect any typing data or analytics? ▼
No! Borno is 100% offline, open-source, and has zero network permissions. None of your keystrokes or data ever leave your computer.
How do I toggle between English and Bengali? ▼
On macOS, use Control + Space or the Globe (🌐) key. On Windows, use F12.
