Engineered for Focus

Everything you love about Avro phonetic typing, redesigned natively for modern macOS.

⚡️

Direct Inline Typing

No floating preview candidates disrupting your visual canvas. Typed Bengali characters stream straight into your document.

🎨

Adobe Illustrator Ready

Custom-tuned for Adobe Creative Cloud (Illustrator, Photoshop, InDesign), Figma, and VS Code with zero cursor jumps.

🔒

100% Offline & Private

Runs entirely locally with zero network requests or telemetry. Your keystrokes never leave your Mac.

🚀

Apple Silicon Native

Compiled natively with Rust and Swift for ultra-low latency, sub-millisecond response, and negligible memory footprint.

🌐

Full Avro Rule Engine

Supports all standard Avro phonetic mappings, conjuncts, and transliteration rules seamlessly.

⌨️

Instant Keyboard Switch

Seamlessly switch between English and Borno using macOS native Globe (🌐) key or Ctrl + Space shortcuts.

Simple 3-Step Setup

Get up and running in less than 60 seconds.

1

Download & Run

Download the DMG or run the 1-line installer in Terminal:

curl -fsSL https://raw.githubusercontent.com/yahiabinzaman/macbangla/main/scripts/install.sh | bash
2

Enable in Settings

Go to System Settings → Keyboard → Input Sources, click +, search for Borno, and click Add.

3

Start Typing

Press the Globe key or Ctrl + Space to switch to Borno and write in Avro phonetic anywhere on your Mac.
